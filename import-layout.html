Import lab layout into the calendar

Reads lab-layout.json — the beds and tables traced in the 3D lab model — and writes them into this calendar’s rooms as stations. Also stores the building outline so the floor view can draw the plan.

This replaces each listed room’s station list. Any beds or tables you added by hand in those rooms are overwritten by the ones from the model. Everything else — room names, column order, bookings, inventory, notes — is untouched. Run the preview first; it changes nothing.
