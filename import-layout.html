Import lab layout into the calendar

Reads the lab from the 3D model — its beds, tables, furniture, walls and doors — and writes them into this calendar. The rooms get their stations, and the floor view gets the building to draw.

To copy a fresh layout over from the model: open the model, press ⧉ Copy for board at the top, then paste it in the box below and press Use this. That replaces the file for this run, so the model and the board match without anyone regenerating anything.

Leave the box empty and this page uses lab-layout.json from the repo, the way it always has.

This replaces each listed room’s station list. Any beds or tables you added by hand in those rooms are overwritten by the ones from the model. Everything else — room names, column order, bookings, inventory, notes — is untouched. Run the preview first; it changes nothing.
